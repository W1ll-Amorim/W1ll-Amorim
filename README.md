### [Sistema-alarme-noturno-iot](https://github.com/W1ll-Amorim/alarme-noturno-iot)

Sistema de alarme IoT desenvolvido com Arduino utilizando sensor LDR, buzzer, LEDs e display LCD.

O sistema monitora a luminosidade do ambiente e ativa automaticamente o modo de alerta em condições de baixa iluminação.

#### Tecnologias e componentes
![Arduino](https://img.shields.io/badge/Arduino-00979D?style=flat-square&logo=arduino&logoColor=white)
![C++](https://img.shields.io/badge/C%2B%2B-00599C?style=flat-square&logo=cplusplus&logoColor=white)

- Photoresistor (LDR)
- LCD
- LEDs
- Buzzer
